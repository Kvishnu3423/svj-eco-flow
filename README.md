# SVJ Eco Flow Systems — React + Vite

A fully structured React + Vite project converted from the original HTML design.

## Project Structure

```
SVJ/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── styles/
    │   └── global.css
    └── components/
        ├── Navbar.jsx / Navbar.css
        ├── Hero.jsx / Hero.css
        ├── Services.jsx / Services.css
        ├── AMC.jsx / AMC.css
        ├── Expertise.jsx / Expertise.css
        ├── Contact.jsx / Contact.css
        └── Footer.jsx / Footer.css
```

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech Stack
- React 18
- Vite 4
- Font Awesome 6 (via CDN)
- Google Fonts — Inter (via CDN)
- CSS Modules (co-located per component)
